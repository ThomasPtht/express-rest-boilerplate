# Express REST API Boilerplate

A REST API boilerplate built with Express, TypeScript, Prisma and PostgreSQL.

## Features

- Auth JWT (register, login)
- CRUD example (todos)
- MVC architecture (controllers, routes, middlewares)
- TypeScript
- Error handling middleware

## Tech Stack

- **Framework** — Express
- **Database** — PostgreSQL + Prisma
- **Auth** — JWT (jsonwebtoken) + bcryptjs
- **Language** — TypeScript

## Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/ton-pseudo/express-rest-boilerplate
cd express-rest-boilerplate
```

### 2. Install dependencies

```bash
npm install express prisma @prisma/client bcryptjs jsonwebtoken dotenv cors
npm install -D typescript @types/express @types/bcryptjs @types/jsonwebtoken @types/cors ts-node-dev @types/node
```

### 3. Configure environment variables

```bash
cp .env.example .env
```

Fill in the values in `.env`.

### 4. Initialize TypeScript

```bash
npx tsc --init
```

### 5. Initialize Prisma

```bash
npx prisma init
```

### 6. Run database migrations

```bash
npx prisma migrate dev --name init
```

### 7. Generate Prisma client

```bash
npx prisma generate
```

### 8. Start the dev server

```bash
npm run dev
```

## Environment Variables

| Variable       | Description                  |
| -------------- | ---------------------------- |
| `DATABASE_URL` | PostgreSQL connection string |
| `JWT_SECRET`   | Secret key for JWT tokens    |
| `PORT`         | Server port (default: 3001)  |

## API Endpoints

### Auth

| Method | Endpoint             | Description         |
| ------ | -------------------- | ------------------- |
| POST   | `/api/auth/register` | Register a new user |
| POST   | `/api/auth/login`    | Login               |

### Todos

| Method | Endpoint         | Description   |
| ------ | ---------------- | ------------- |
| GET    | `/api/todos`     | Get all todos |
| POST   | `/api/todos`     | Create a todo |
| PUT    | `/api/todos/:id` | Update a todo |
| DELETE | `/api/todos/:id` | Delete a todo |
